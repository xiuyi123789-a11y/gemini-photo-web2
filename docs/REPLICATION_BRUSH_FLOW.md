# 图像复刻：正式 Prompt 与涂抹流程交付（v1.5.0 候选）

日期：2026-10-26。基线：`21272f940c571f2a57e9c4f9246e7b73bb93be4d`（P0 修复）。修复分支：`codex/replication-brush-flow`。本轮只修改图像复刻及必要的共享契约、文档和测试。没有真实付费预测、没有生产部署或生产数据库修改。

## 用户操作

1. 上传想保留的场景照片，以及要换进去的同一款新产品的多角度图。
2. 点击“识别产品与替换位置”。o4-mini 先分析参考产品，再按类别、用途和场景关系寻找原图中的对应主体，不要求新旧颜色、品牌或造型相似。识别步骤不会生图。
3. 用画笔涂满要替换的整个产品。可调画笔大小、用橡皮擦保留袜子/裤脚、撤销、清空、放大至 400% 并拖动画面；支持鼠标和 Pointer Events。系统根据涂抹与 AI 位置的交集显示选中了哪些物品，无须用户勾选实例。
4. 确认本次费用并点击“开始替换”。这次明确点击先保存本地分析确认 revision，再提交生成；没有额外的“确认分析内容”步骤。输出设置和完整特征放在可选展开区，补充要求可以留空。

不再显示手写替换对象输入框或多边形顶点工具。若分析没有找到对应主体，明确提示并阻止生成；不会猜测另一个产品。旧分析没有定位信息时，仅恢复查看，不自动收费重分析。

## Prompt 与图片输入

- 用户提供的正式生成 Prompt 保存在 `server/replication-generation-prompt.txt`。原文约束保留，运行时仅填入三处占位符：产品特征分析、待替换主体及位置、补充要求。占位符一次替换，不递归解释用户文本里的占位符。
- `server/replication-prompts.js` 的 `generationPrompt()` 不再使用旧英文模板或旧优先级。版本记录为 `replacement-v3.0`；分析定位模板为 `analysis-v2.1`。
- 模型标识不变：分析 `openai/o4-mini`，生成 `google/nano-banana-2`；分析仍使用 `reasoning_effort: low`、`max_completion_tokens: 4096`。
- 分析 `image_input` 顺序不变：原图、全部产品参考。输出为每个主体增加原图归一化 `[x,y,width,height]` 的 `bbox`，严格检查坐标，允许明确返回零主体。
- 生图顺序：**未加标记的场景原图 → 全部新产品参考 → 最后一张蓝色区域指引图**。动态位置字段会明确这三个角色和图片编号，指引图不会混入产品参考列表。
- 区域指引图由服务器根据实际编辑遮罩生成，最长边不超过 1536 像素，私有保存为 `guide.png`。它是普通视觉指引图片，并非虚构的供应商原生 mask 参数。当前最多 1+6+1=8 张，低于 [Nano Banana 2 官方页面](https://replicate.com/google/nano-banana-2) 标示的 14 张输入上限。

## 涂抹、复核和合成

新生成请求增加可选的 `brush: {version:1, strokes:[{tool,size,points}]}`；工具为 paint/erase，点坐标绑定经过 EXIF 校正的原图，笔宽按原图短边归一化。最多 300 笔、6000 点；后端独立校验所有值，拒绝越界、超量、空画面及全擦除。

`shared/replication-brush.js` 提供前后端相同的低分辨率位置匹配逻辑。服务端重新计算所选主体，并与请求中的 ID 集合核对；涂在无关背景、或伪造另一个主体 ID 的请求在生图前返回 422。该复核是 **AI 定位与涂抹的位置核对，不是额外模型推理或像素语义分割**。

`server/replication-composite.js` 按原图分辨率栅格化完整笔画历史，正确处理橡皮擦孔洞。未涂抹处、擦除后留白处以及未选中主体的识别范围保留原图像素；过渡仅发生在允许编辑区内。每个所选主体分别做变化检查，仍保留原始候选、合成图和人工身份审核。原图回传不视为替换成功。

新产品轮廓或阴影超出涂抹区时，区外仍会保留旧像素，因此必须涂满产品并留出必要空间；不能把几笔中心标记等同于自动分割整件产品。UI 已明确提示，原图预览始终可见实际蓝色范围。

旧版多边形数据契约保留，旧任务可只读查询、恢复已有预测和查看结果；新页面不再提供多边形操作。不迁移或重建历史预测。

## P0 保护保持有效

本次没有修改供应商创建重试策略或存储锁协议。GET 仍只读；显式 resume 仍只能恢复已有 attempt；无 job 时必须原子封存后才能解除费用保护。未知提交、网络中断、404、重复点击及服务重启都不能授权新预测。画笔移动、擦除、缩放和主体位置复核不调用模型。

提交后的笔画和指引图随原 job 持久化，刷新恢复相同 requestId/jobId/预测及涂抹范围，费用确认保持未勾选。提交前尚未保存的涂抹属于页面草稿，刷新后需要重画，识别结果可恢复而不会自动重分析。

## 边界与回滚

o4-mini 的 bbox 是近似定位，不能保证语义识别或遮挡分割准确。页面会显示当前匹配的主体，允许查看 AI 位置；涂抹范围仍由用户复核。未进行真实模型结果质量验收，不把 Mock、提示词替换或页面正常视为真实替换效果已验证。P0 报告中的真实 PostgreSQL 多连接并发验证门槛仍保留。

当前仅提交修复分支，生产未切换，无需生产回滚。如未来撤回此流程，优先在当前后端设置 `REPLICATION_ENABLED=false` 关闭新入口并完成原任务核对。只有这批 brush 任务全部进入终态，或已暂停复刻 API 后，才可回到 P0 基线 `21272f9`；旧后端不理解 brush，不能用来恢复或重新合成未完成的涂抹任务。保留新 job、指引图、候选和数据库记录，不自动重提。不得回到存在 GET 唤醒缺陷的 `3c9c7bb` 接收复刻流量；回滚也不会取消远端预测或撤销费用。

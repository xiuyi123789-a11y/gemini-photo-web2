## 当前功能与操作

- 工作室提供图片分析、生成、修图、图像复刻和灵感知识库。首页选择风格与比例、输入需求并发送，素材准备完成后启动一次生成。
- 图像复刻：上传一张场景原图和最多六张产品参考图 → 在原图涂抹替换范围 → 查看张数与费用提示 → 点击生成 → 查看和下载结果。产品分析可选，另行计费；分析失败、定位不准、摘要留空或过期都不阻止按参考图和涂抹生成。可用输出数量和分辨率受服务配置及供应商限制。
- 未涂抹、全部擦除或素材不可读取时，需要修正后再提交；有效涂抹以用户选择为准。提交失败保留素材和编辑，不自动重新发起收费请求。
- 刷新后尽可能恢复未提交的素材、涂抹、要求和设置；已保存结果可查看。旧任务状态不明时保留查询和取消入口，主动新建任务时须注意新旧任务都可能计费。

## 架构与代码逻辑

浏览器 React 前端 → Caddy HTTPS → Node.js / Express 后端 → Replicate；PostgreSQL 保存账号、会话、知识库和任务记录，持久卷保存图片。生产通过 Docker Compose 运行，Node.js 24、PostgreSQL 17。

- 复刻前端位于 `components/ImageReplicationView.tsx`，素材、草稿和请求分别由 `services/replicationService.ts`、`services/replicationDraft.ts` 管理；共享模型和状态约定位于 `shared/replication-contract.js`。
- 后端 `server/replication.js` 受理素材和任务，相关 validation、store、worker、provider 模块负责校验、持久化、执行及供应商通信。分析使用 Gemini 2.5 Flash，生成使用 Nano Banana 2，均通过 Replicate。
- 服务端验证账号、图片格式与大小、素材关联和有效涂抹；请求 ID 与预测尝试用于防止同一请求重复提交。提交结果不明时保留记录并核对原任务，不自动重发；用户可明确发起新任务。
- 结果和图片按账号隔离；页面优先显示小预览，再加载清晰预览，完整原图按需查看或下载。用户 Token 保存在当前标签页，也可使用服务端配置的共享 Token。

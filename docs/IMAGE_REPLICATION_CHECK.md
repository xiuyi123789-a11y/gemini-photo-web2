# 图像复刻接入与自检记录

日期：2026-10-23，Asia/Shanghai。正式板块版本：v1.3.0。

## 接入结果

分析按指定链接使用 openai/o4-mini，区别于名称相近的 GPT-4o mini。生图使用 google/nano-banana-2。参数已对照 Replicate 当前公开 schema，收费预测使用官方模型的 /v1/models/{owner}/{model}/predictions 接口。

分析与生成都将场景原图放在第一张，全部新产品参考紧随其后，并显式标注各图片职责。生图使用 match_input_image、指定模型分辨率及 PNG 格式，不开启额外图像搜索或网页搜索。

## 真实连通性

使用本项目代码绘制的场景与产品测试素材，未使用真实用户图片。本次共创建 3 次真实预测：

| 模型 | 用途 | 实际结果 | 模型耗时 |
| --- | --- | --- | --- |
| openai/o4-mini | 原图与产品参考综合分析 | succeeded，返回中文产品分析 | 约 10.4 秒 |
| google/nano-banana-2 | 初次 1K 产品替换 | succeeded，图片返回与保存成功 | 约 10.4 秒 |
| google/nano-banana-2 | 产品框选保护后的 1K 产品替换 | succeeded，完成原图合成、页面对比及 PNG 下载 | 约 10.3 秒 |

首次结果的部分背景受到模型重绘，因此正式实现增加必填的产品区域框选。生成后将模型图片对齐原图，并仅把框内的像素合成回原图。边界在框内轻微羽化；最终 PNG 保持原图像素尺寸。1K/2K/4K 指模型生成分辨率，不是最终合成文件尺寸。

最后一张结果为 1120 × 700。按 UI 实际框选的像素区域（左 448、上 126、右边界 729、下边界 589）检查：

- 框外比较 653,897 个像素，变化数为 0。
- 框内变化 127,384 个像素，确认生成内容实际进入合成结果。
- 下载内容是有效 PNG，实际尺寸与原图一致。

以上核验确认接口和场景保护链路连通，不代表所有产品的结构与文字均能完美还原。产品保真及框内其他细节仍需用实际多角度照片验收；框选应覆盖完整新旧产品及必要阴影，避免包含无关物体。
